# NeuroRL

NeuroRL is an adaptive brain-computer interface (BCI) decoding system that uses reinforcement learning to help an AI model adapt to non-stationary neural signals. The project builds an OpenEnv-based simulated neural environment where a model observes 20-channel Poisson spike trains representing cortical activity and decodes them into motor intents while the underlying neural code gradually drifts over time. A GRPO-trained Qwen3 model is evaluated using a reward function that considers intent accuracy, confidence calibration, feature attribution, decisiveness, and sustained performance, with dedicated training notebooks, evaluation scripts, held-out scenarios, visualization tools, and a deployable environment included in the repository. The project explores a central challenge in practical BCIs: maintaining reliable neural decoding as brain signals change, with the long-term aim of enabling AI-powered decoders that can adapt continuously rather than relying on repeated manual recalibration. 

## Hackathon Experience

NeuroRL was developed as part of the **OpenEnv Hackathon (Meta × PyTorch × Hugging Face) 2026**, organized by **Scaler School of Technology**. The hackathon provided an exciting opportunity to explore the intersection of reinforcement learning, neuroscience, and brain-computer interfaces while turning an ambitious research idea into a working prototype under real time constraints. I particularly enjoyed the experience of experimenting with OpenEnv, reinforcement learning, and neural signal simulation, while continuously iterating on the system and learning how different components came together in practice. More than just building a project, the hackathon made the process of exploring an idea I genuinely care about both technically challenging and deeply enjoyable.
